# Kiambu Appliance Care

A responsive multi-page home appliance repair website serving Kikuyu, Thogoto, Banana, Kinoo, Regen, Zambezi, Gitaru, Sigona, Gikambura, Juja, Kimbo, Kamakis, Membley, Ruiru, Tigoni, Limuru, and Redhill.

The site includes dedicated Services, About, Service Areas, and Contact pages, plus individual detail pages for every appliance repair service.

## Local preview

Open `index.html` in a web browser.

## cPanel deployment

Upload the contents of the project to the domain's `public_html` directory. Keep `index.html`, `styles.css`, `script.js`, `.htaccess`, and the `assets` directory at the root of `public_html`.
